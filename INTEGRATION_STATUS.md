# Using the source helpers

1. Install MATLAB R2026b and the toolboxes/support packages required by the official MathWorks Minidrone Competition guide.
2. Obtain the official starter using PX4MultiCopterPerceptionAndControlStart.
3. The files here are helper functions for the Mavericks project. They are not a complete runnable Simulink project: the matching Image Processing and Guidance MATLAB Function block wiring and interfaces must also be supplied and documented before this is advertised as a runnable release.
4. Keep these helpers in the root of the matching Mavericks project. Do not change UAV physics or controller parameters to improve a score.
5. Verify source resolution, project checks, simulation, and code generation on the completed integration before shipping.

Official starter and competition guide:
https://in.mathworks.com/content/dam/mathworks/mathworks-dot-com/academia/student-competitions/minidrone-competition/mathworks-minidrone-competition-guidelines-px4-multicopter.pdf
