# Running the supplied portable package

Download [the portable ZIP](downloads/Mavericks_Minidrone_Portable_Final.zip), extract it and run `OPEN_PROJECT` from the extracted folder in MATLAB. It contains the supplied `.mlproj`, process guide and example tracks. MATLAB R2026b and the required official toolboxes/support packages are needed; see the included instructions and official competition guide for setup.

The root MATLAB files are readable helper sources. The ZIP carries the corresponding Simulink project and transfer material supplied by the owner. Publication did not rerun flights, code generation, or hardware tests. Keep MathWorks starter attribution and its original terms. Preserve local track changes when opening or reusing an extracted project.

The saved simulation image is in [screenshots](screenshots/INDEX.md). A demo video has not been provided in the supplied deliverables folder.
